# 🛡️ Rede de Proteção — Portal Conselho Tutelar

**Informação que protege. Conhecimento que transforma.**

## 📖 Sobre o projeto

O **Rede de Proteção — Portal Conselho Tutelar** é um projeto acadêmico de extensão desenvolvido com o objetivo de disseminar informações sobre o Conselho Tutelar, conscientizar a comunidade sobre os direitos das crianças e dos adolescentes e apresentar os principais canais de orientação e proteção.

A proposta é utilizar a tecnologia como ferramenta de informação e conscientização social, facilitando o acesso a conteúdos relacionados ao Estatuto da Criança e do Adolescente (ECA).

O projeto busca contribuir para que a população compreenda a importância do Conselho Tutelar e reconheça situações que possam representar ameaça ou violação dos direitos de crianças e adolescentes.

## 🎯 Objetivos

- Apresentar à comunidade o papel e as atribuições do Conselho Tutelar.
- Divulgar informações sobre os direitos previstos no Estatuto da Criança e do Adolescente (ECA).
- Orientar sobre situações em que o Conselho Tutelar pode ser procurado.
- Divulgar canais oficiais de orientação e denúncia.
- Promover a conscientização sobre a responsabilidade coletiva na proteção de crianças e adolescentes.
- Aplicar conhecimentos de desenvolvimento web na construção de uma solução digital com finalidade social.

| Tecnologia | Aplicação |

## ⚙️ Funcionalidades

O protótipo apresenta as seguintes funcionalidades:

- **Página inicial:** apresentação do projeto e sua finalidade.
- **Informações sobre o Conselho Tutelar:** explicação sobre o órgão e sua atuação.
- **Direitos fundamentais:** conteúdos educativos sobre os direitos estabelecidos pelo ECA.
- **Orientações à comunidade:** exemplos de situações em que o Conselho Tutelar pode ser procurado.
- **Rede de proteção:** informações sobre a participação da família, dos serviços públicos e da sociedade.
- **Canais de atendimento:** divulgação de meios nacionais de orientação, como o Disque 100 e o telefone 190 para emergências.
- **Menu responsivo:** navegação adaptada para diferentes tamanhos de tela.
- **Botão de saída rápida:** redirecionamento para o Google por meio do JavaScript.

## 📁 Estrutura do projeto

A organização dos arquivos está dividida entre a parte visual do site e os recursos complementares.

```text
portal-conselho-tutelar/
│
├── frontend/
│   │
│   ├── index.html
│   │
│   └── assets/
│       ├── style.css
│       └── script.js
```

**Descrição dos arquivos:**

- `index.html`: contém a estrutura e o conteúdo das páginas.
- `assets/style.css`: concentra as regras de estilização e responsividade.

## 🚀 Como executar o projeto

Para executar o projeto localmente, siga estas etapas:

### 1. Clonar o repositório

Abra o terminal e execute:

```bash
git clone URL_DO_REPOSITORIO
```

Substitua `URL_DO_REPOSITORIO` pelo endereço do repositório no GitHub.

### 2. Acessar a pasta

```bash
cd portal-conselho-tutelar
```

### 3. Executar o projeto

**Opção 1 — Visual Studio Code**

- Abra a pasta do projeto no Visual Studio Code.
- Localize o arquivo `frontend/index.html`.
- Utilize a extensão Live Server para abrir o site no navegador.

**Opção 2 — XAMPP**

- Copie a pasta do projeto para o diretório `htdocs` do XAMPP.
- Inicie o serviço Apache.
- Acesse o seguinte endereço no navegador:

```text
http://localhost/portal-conselho-tutelar/frontend/
```

## ⚠️ Aviso importante

Este projeto possui finalidade exclusivamente acadêmica, educativa e informativa.

O site não representa um canal oficial do Conselho Tutelar, não recebe denúncias, não realiza atendimentos e não substitui os serviços públicos responsáveis pela proteção de crianças e adolescentes.

O botão de saída rápida realiza apenas o redirecionamento para outra página. Ele não apaga o histórico do navegador, registros de rede ou outros rastros de navegação, portanto não garante privacidade total.

Os contatos e endereços dos Conselhos Tutelares locais devem ser confirmados em fontes oficiais antes de qualquer publicação ou utilização pública do projeto.

Não devem ser inseridos no site dados pessoais ou relatos que permitam identificar crianças e adolescentes.
